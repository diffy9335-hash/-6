# VELTON
Для запуска через Telegram создай бота в BotFather и рядом с compose.yaml создай файл .env:
```
BOT_TOKEN=токен_бота
APP_URL=https://твой-домен
```
Направь HTTPS-домен или туннель на порт 3000. Выполни docker compose up -d --build и отправь боту /start. Для polling используй один экземпляр бота с отключённым webhook. На хостинге с Dockerfile укажи внутренний порт 3000, обе переменные окружения и постоянный диск в /app/data. Проверка доступности — GET /health.

Для локальной пробы оставь BOT_TOKEN пустым и задай DEMO_MODE=1 в .env. Открой http://localhost:3000. Все посетители деморежима используют один тестовый профиль. Для демо используй отдельную базу.

Без Docker нужен Python 3.10+. Задай переменные в окружении процесса и запусти python server.py из папки проекта. Файл .env автоматически читает только Docker Compose.
